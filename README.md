## 🔩 Selected Work

- **[LocRest](https://github.com/quonaro/LocRest)** — self-hosted ngrok alternative built on chisel. A Go server that provisions and manages reverse tunnels; clients use stock chisel, and a tunnel spins up from a single `curl | bash`.
- **[Lota](https://github.com/quonaro/Lota)** — declarative task runner in Go. Commands, arguments, variables, dependencies and hooks defined in YAML — I run it in every project here.
- **[MiniMin](https://github.com/quonaro/MiniMin)** + **[MiniMinSync](https://github.com/quonaro/MiniMinSync)** — web panel for modded Minecraft servers (Docker orchestration, mod management, Prism-compatible exports) with a desktop client that syncs modpacks to Prism / MultiMC.
- **[acp2api](https://github.com/quonaro/acp2api)** — OpenAI-compatible HTTP gateway for ACP agents. Point any OpenAI client at it and drive Devin, Claude, Codex or OpenCode CLIs over `/v1/chat/completions`.
- **[fias-public-api](https://github.com/quonaro/fias-public-api-python)** — unofficial FIAS (federal address system) clients in **Python** and **[Go](https://github.com/quonaro/fias-public-api-go)**, sync and async.
